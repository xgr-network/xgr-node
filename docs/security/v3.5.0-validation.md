## Limits

The original advisory attachment scripts were blocked by the browser and were
not executed; the attack regression is an independently constructed local
reproduction. This is not an external security audit or a production-state
rehearsal. Genuine Mainnet validator proofs and an approved production height
remain prerequisites; the candidate does not fabricate either. Broader unrelated
repository end-to-end suites were not run. Initial unsafe worker-enabled startup
was rejected by automatic approval review, corrected and replaced with the
explicitly isolated successful run; see the private worklog.
